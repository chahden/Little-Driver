# Floating controls

Option 3 visual style for Sprint2Prototype. Reusable button visuals and icons share FloatingControlsAtlas.png (1024 × 512, no mipmaps).

- Existing Button actions and SprintHoldControl components remain on the original control objects.
- Edit the visual prefabs here for colours and icons. Button targetGraphic points to the coloured Fill image.
- Canvas scaling uses a 1280 × 720 reference with width/height matching. Safe Area adapts to screen edges through TabletSafeArea.
- DriverPortraitUI keeps its unbelted/red and belted/green states through SprintPrototypeHUD.

Checked in landscape tablet previews at 16:10 and 4:3. Physical-device performance remains to be checked.
